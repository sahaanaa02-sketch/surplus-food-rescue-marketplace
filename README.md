# 🥗 ZeroWasteBite - Surplus Food Rescue Marketplace

A full-stack web application designed to connect restaurants, bakeries, and grocery stores with conscious consumers to rescue fresh, unsold surplus food at discounted prices—reducing food waste and carbon emissions.

---

## 🌟 Key Features

### 👤 Customer Features
* **Browse Offers:** View discounted surplus food deals from local merchants with real-time stock levels.
* **Filter & Search:** Filter meals by category (Bakery, Meals, Snacks) or search by venue name.
* **Instant Reservation:** Reserve surplus meals in a few clicks and receive a pickup verification token.

### 🏪 Business / Merchant Features
* **Merchant Portal:** Add and manage active surplus food listings, pricing, and pickup windows.
* **Bulk Import (CSV):** Easily upload large inventories via CSV files using the integrated modal.
* **Sales Analytics:** Track offer performance and sales reports.

### 🛡️ Admin & Reporting
* **Environmental Impact Dashboard:** Track total food rescued (kg), CO₂ emissions prevented, and customer cost savings.
* **Role-Based Access Control (RBAC):** Secure routing and access control for Customers, Businesses, and Admins.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router DOM, Axios, Custom CSS3 / Flexbox / Grid
* **Backend:** FastAPI (Python) / Node.js Express (Swagger API Specs)
* **API Documentation:** Interactive Swagger UI
* **Database:** PostgreSQL / MongoDB
